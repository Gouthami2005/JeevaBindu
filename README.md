# Jeeva-Bindu 🩸

## Overview
Jeeva-Bindu is a real-time blood donor emergency response application developed for Android using Kotlin and Jetpack Compose. The system is designed to bridge the gap between blood donors, hospitals, and patients during medical emergencies by enabling rapid communication, donor availability tracking, and emergency alert management.

The application focuses on minimizing emergency response time through location-based donor connectivity and real-time notification mechanisms.

## Key Features

1) Donor Management
- Secure donor registration and login using Firebase Authentication
- Donor profile management with blood group, age, and location details
- Availability status tracking for active donors
- Donation eligibility calculation based on the 90-day donation rule

2) Emergency Alert System
- Real-time emergency blood request creation
- Alert posting with hospital name, blood group, and emergency details
- Notification badge indicator for new alerts
- Alert status management (Active / Resolved)

3) Response Management
- “I’m Coming” response system for donors
- Real-time responder updates visible to users
- Community-driven emergency coordination

4) Blood Compatibility Module
- Integrated blood compatibility reference chart
- Donor-recipient compatibility visualization

5) Data & Security
- Firebase Firestore integration for cloud-based real-time data storage
- Firebase Authentication for secure user access
- Structured NoSQL database collections for alerts, donors, and responses
